Four presentational React components compose the chat surface: `ChatHeader` shows branding, online status, language toggle, audit-log drawer trigger, and settings sheet; `ChatBody` renders a scrollable message list by dispatching on each message's `kind` discriminator to specialized bubble/card components from `@/components/Bubbles` and `@/components/cards`; `ChatInput` handles text entry, Enter-to-send, simulated voice-note recording, and photo attachment via a settings sheet; `QuickReplies` renders horizontal pill buttons for suggested follow-ups. All components are stateless consumers of the global store exposed through `useApp` (from `@/store/useApp`) and push mutations outward via side-effect functions from `@/store/director` (`onUserText`, `onVoiceNote`, `onQuickReply`), keeping UI purely reactive with no local business logic. Styling is entirely Tailwind CSS classes with utility helpers like `cn` from `@/lib/utils`.
