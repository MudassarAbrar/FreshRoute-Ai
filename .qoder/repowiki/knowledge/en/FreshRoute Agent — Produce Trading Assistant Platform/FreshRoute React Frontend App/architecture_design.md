The app entry `src/main.tsx` mounts `<App/>`, which assembles the UI tree in `src/App.tsx`: a `PhoneFrame` shell wraps a `PriceTicker`, `ChatHeader`, `ChatBody`, `QuickReplies`, `ChatInput`, and conditionally rendered `PhotoSheet`/`SettingsSheet` plus an always-visible `AuditDrawer`. All components consume a single global state slice from `@/store/useApp` (Zustand), with `director.ts`'s `boot()` function initializing side effects on first render. The chat conversation UI (`chat_ui`) and reusable shell/overlay components (`app_shell`) are both mounted by this top-level `App` component, sharing the same store for cross-cutting concerns like sheet visibility and chat messages. External services are isolated under `src/lib/` (`gemini.ts` for AI via Supabase Edge Function proxy, `supabase.ts` for DB, `engine.ts` for business logic) and accessed only through these modules rather than directly from components.
