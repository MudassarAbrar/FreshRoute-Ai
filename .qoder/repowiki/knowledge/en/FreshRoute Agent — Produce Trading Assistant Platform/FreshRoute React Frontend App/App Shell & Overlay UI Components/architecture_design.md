Each file is a self-contained presentational React component exported as a named function component. They share a common dependency direction: read UI state from `@/store/useApp` (e.g. `drawerAudit`, `setSheet`, `ticker`, `aiMode`) and dispatch actions via `@/store/director` functions like `onPhotosChosen` and `refreshAiMode`. Styling is exclusively Tailwind CSS with the `cn` utility from `@/lib/utils`; icons come from `lucide-react`. Overlays (`AuditDrawer`, `PhotoSheet`, `SettingsSheet`) follow an identical pattern: a full-screen backdrop with `backdrop-blur` plus a slide-up/slide-in panel positioned absolutely inside the phone frame. `PhoneFrame` is the top-level chrome that renders a desktop-side hero panel on large screens and wraps child content in a simulated iPhone container. `Bubbles.tsx` provides message-type primitives (`AgentBubble`, `UserBubble`, `TextUser`, `VoiceUser`, `PhotosUser`, `DayDivider`, `EncryptionNote`) consumed by the chat view, while `PriceTicker` renders a marquee-style mandi-rate banner at the top of the app.
