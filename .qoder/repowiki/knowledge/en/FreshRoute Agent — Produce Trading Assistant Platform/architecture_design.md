The repository is organized as a single Vite + React SPA under `freshroute/` plus a product PRD at the repo root. The frontend (`src/`) composes a chat shell, phone-frame UI, and overlay panels around a Zustand store (`store/director.ts`, `store/useApp.ts`) that drives all user-facing state. Business logic is split into `lib/`: `engine.ts` holds the recommendation/scenario logic, `gemini.ts` calls Google's multimodal model for image and text understanding, `supabase.ts` persists data via Supabase JS client, and `format.ts` / `utils.ts` provide shared helpers. A Supabase Edge Function (`supabase/functions/gemini-proxy/index.ts`) proxies Gemini API calls from the browser to keep secrets server-side, while `supabase/migrations/` defines the relational schema and seed data. The PRD (`FreshRoute_Agent_PRD.md`) documents the end-to-end agent workflow, state machine, and data flow that the frontend implements in MVP form; future backend services (Intake, Media Processing, Recommendation Engine, Workflow Orchestrator, Notifications) are described as planned extensions beyond this SPA.
